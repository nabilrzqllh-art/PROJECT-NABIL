Sistem Pemantauan Paras Air & Amaran Banjir Pintar

Manual pengguna untuk pemasangan, pengendalian dan penyelenggaraan sistem IoT berasaskan ESP32 dan Firebase.

Pengenalan Keperluan Pemasangan Pengendalian Status & Amaran Penyelesaian Masalah

1. Pengenalan

Sistem ini mengesan paras dan kekeruhan air secara masa nyata dan menyimpan log data sejarah ke pangkalan data Firebase. Amaran dipaparkan melalui LED penunjuk setempat dan pemberitahuan terus ke aplikasi pengguna.

Untuk siapa sistem ini?

PendudukKawasan berisiko banjir.
Pihak berkuasa & penyelamatPihak berkuasa tempatan dan pasukan penyelamat.
Penyelia tapakPemantauan kualiti air.

2. Keperluan Sistem

Perkakasan

MikrokawalESP32 (modul ZY-ESP32, Wi-Fi & Bluetooth)
PenderiaUltrasonik HC-SR04 (paras air) dan penderia kekeruhan (kejernihan air)
Paparan & amaranLCD 16x2 dan LED Merah, Kuning, Hijau
Bekalan kuasaTransformer 230V ke 12V-0-12V AC, papan PSU custom (12V, 9V, 5V) dan regulator LM2596

Perisian & rangkaian

  • Firebase Realtime Database / Firestore untuk simpanan log berterusan.
  • Aplikasi web atau telefon pintar yang disambungkan ke Firebase.
  • Wi-Fi 2.4GHz yang bersambung ke Internet.

3. Pemasangan & Persediaan

Sambungan fizikal dan kuasa

  1. Sambungkan palam utama transformer 230V ke soket dinding.
  2. Pastikan lampu indikator pada papan PSU dan modul LM2596 menyala. Ini menandakan bekalan 5V dan 3.3V stabil.
  3. Arahkan penderia ultrasonik tegak ke permukaan air.
  4. Rendamkan penderia kekeruhan dalam laluan air.
Keselamatan: Letakkan ESP32, PSU dan LM2596 di dalam perumah kalis air yang kering.

Konfigurasi Wi-Fi dan Firebase

  1. Pastikan ESP32 telah diprogramkan dengan Firebase Host URL dan Database Secret / API Key yang betul.
  2. Sambungkan ESP32 ke liputan Wi-Fi 2.4GHz berhampiran.
  3. Apabila berjaya bersambung, ESP32 akan menghantar log paras air dan kekeruhan ke Firebase secara automatik dari masa ke semasa.

4. Pengendalian

Menghidupkan sistem

  1. Hidupkan suis utama bekalan kuasa AC.
  2. Skrin LCD 16x2 menyala dan memaparkan status permulaan sistem.
  3. Sistem mula mengemas kini bacaan penderia dan menyimpan log ke Firebase.

Mematikan sistem dengan selamat

  1. Pastikan penghantaran data log ke Firebase telah selesai.
  2. Matikan suis utama bekalan kuasa AC.
  3. Cabut palam dari soket dinding.

6. Penyelesaian Masalah

IsuPunca biasaTindakan
Data tidak tersimpan di FirebaseTiada sambungan Wi-Fi atau API Key Firebase terputusSemak router Wi-Fi 2.4GHz. Sahkan semula URL / API Key pada kod ESP32.
LCD tidak menyala / kosongTiada bekalan kuasa atau kontras longgarSemak sambungan 5V PSU dan laras potensiometer kontras LCD.
LED status tidak bertukarPin GPIO atau LED terputusSemak wayar pada pin LED Merah, Kuning dan Hijau.
Bacaan paras air tidak tepatLensa ultrasonik terhalang atau kotorBersihkan permukaan HC-SR04 daripada habuk atau titisan air.
Bacaan kekeruhan sentiasa keruhProbe optikal bersalut kotoran / lumpurLap kaca probe dengan kain lembut.

Penjagaan berkala

  • Bersihkan cermin probe penderia kekeruhan secara berkala.
  • Pastikan perumah elektronik sentiasa kering dan kalis air.
